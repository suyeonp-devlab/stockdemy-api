# 커밋 메시지 형식
# <type>: <subject>
# -----------------------------------------------
# feat      : 새로운 기능 추가
# fix       : 버그 수정
# wip       : 작업 진행 중 (미완성 커밋)
# refactor  : 리팩토링 (기능 변경 없음)
# style     : 코드 스타일 (포맷팅, 세미콜론 등 로직 변경 없음)
# docs      : 문서 수정 (README, 주석 등)
# test      : 테스트 코드 추가/수정
# chore     : 설정, 빌드, 패키지 관리 등
